# Radio Rating Autofill

A simple JavaScript utility that automatically selects rating **5** for compatible five-option radio-button questions on a webpage.

## Features
- Groups radio buttons by question.
- Identifies the option corresponding to rating 5.
- Skips questions that do not match the expected structure.
- Displays the number of filled and skipped questions.
- Does not automatically submit the form.

## How to Use
1. Open the webpage containing the rating questions.
2. Open your browser's Developer Tools.
3. Go to the Console tab.
4. Paste the JavaScript code from `rating-autofill.js`.
5. Press Enter to execute.
6. Review the selected answers before submitting.

**Note:** Use only on forms where you are authorized to automate responses. The script selects rating 5 regardless of the actual feedback you might intend to give.
