# NIT Goa Feedback Autofill

A simple JavaScript utility designed to automate the selection of rating options in the NIT Goa feedback form.

## Features
- Automatically identifies radio-button questions.
- Selects rating 5 for compatible five-point rating questions.
- Skips questions that do not match the expected format.
- Displays the number of questions filled and skipped.
- Does not automatically submit the form.

## How to Use
1. Open the NIT Goa feedback form.
2. Press `F12` or open Developer Tools.
3. Navigate to the **Console** tab.
4. Paste the code from `nit-goa-feedback.js`.
5. Press Enter to execute.
6. Review the selected ratings before submitting.

**Disclaimer:** This is an unofficial utility and is not affiliated with NIT Goa. Use it only where automation is permitted and the selected ratings accurately reflect your intended feedback.
